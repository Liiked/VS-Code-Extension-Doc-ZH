
# 入门向导（Walkthroughs）

入门向导通过包含丰富内容的多步骤清单，为用户提供一致的插件上手体验。

**✔️ 应该**

- 使用有帮助的图片为当前入门向导步骤增添上下文。
- 确保图片在不同颜色主题下都能正常工作。尽可能使用带有 VS Code [主题色彩](/references/theme-color)的 SVG。[Visual Studio Code Color Mapper](https://www.figma.com/community/plugin/1218260433851630449) Figma 插件可以轻松为 SVG 应用主题。
- 为每个步骤提供操作（例如，View all Commands）。尽可能使用动词。

❌ 不应该

- 在单个入门向导中添加过多的步骤
- 除非绝对必要，否则不要添加多个入门向导
